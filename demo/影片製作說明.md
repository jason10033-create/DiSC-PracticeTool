# 課後邀請影片：製作說明

這支影片用來在課程結尾邀請學員繼續使用網站（簡報內嵌播放）。做法是用「影片示範頁」自動操作網站、自動加上字幕，你只要按下錄影就能得到成品。

## 一、影片規格建議

| 項目 | 建議 |
|---|---|
| 長度 | 約 1 分 50 秒 |
| 畫面 | 橫式 16:9，錄 1920×1080 |
| 聲音 | 預設無聲，字幕已經燒進畫面（簡報播放時不需要額外開字幕）。想要背景音樂，錄完後在 Clipchamp 加上輕音樂即可 |
| 格式 | Windows 錄影存成 MP4，直接插入簡報就能播放 |

## 三、錄影步驟（約 5 分鐘）

1. 用 **Edge 或 Chrome** 開啟影片示範頁：`https://jason10033-create.github.io/DiSC-PracticeTool/demo.html`
   - 想用淺色畫面錄：網址後面加 `?theme=light`（預設是深色）。
2. 按 **F11** 進入全螢幕，再按 **Ctrl 和 ＋** 把網頁放大到 **150%**（讓簡報播放時字夠大）。
3. 開始錄影（Windows 內建：**Win ＋ Alt ＋ R**；或用 Clipchamp 的螢幕錄製）。
4. 按**空白鍵**，網站就會自動操作並加上字幕，跑完會停在結尾字卡。
5. 停止錄影，把檔案前後多餘的幾秒剪掉（Clipchamp 或照片 App 的修剪功能即可）。
6. 把 MP4 插入簡報（插入 → 視訊 → 此裝置），設定「自動播放」即可。

調整播放速度：網址加 `?speed=1` 是比較慢的速度，`?speed=1.25` 是預設，想更快可用 `?speed=1.5`。

## 四、怎麼改影片上的字

所有字幕和字卡文字都集中在 `js/demo.js` 最上方的「字幕與字卡文字」區塊（`const T = { … }`），一行一句，直接改引號裡的字即可：

- `openTitle`、`openSub`：開場大標與副標
- `home`、`tools1`、`tools2`、`self1`、`self2`、`others1～3`、`adapt1～4`：各段字幕（兩行字幕用 `\n` 分開，第二行會自動縮小）
- `closeTitle`、`closeSub`、`closeLine`、`url`：結尾字卡（網址在這裡改）

改完要重新推送到 GitHub 才會生效；你也可以直接把想改的字告訴我，我幫你改。

## 五、這個示範頁的特性

- **不會留下假資料**：示範過程不寫入資料庫。
- **不需要輸入解鎖密碼**：只有示範頁會自動略過密碼，正式網站的密碼機制不受影響。
- **看到的是真實內容**：教材、題目、四型說明都是網站上的真實內容；「看懂自己」顯示的是一份範例結果（王小明，D 主型帶 i 傾向）。
- **不能手動操作**：示範頁上有一層透明保護，播放中點擊不會有反應，避免誤觸。
- 網址不會出現在網站任何連結裡，也不會被搜尋引擎收錄。

## 六、常見問題

| 狀況 | 處理方式 |
|---|---|
| 畫面一直停在黑底的說明頁 | 還沒按空白鍵；或網頁尚未載入完成，等 3 秒再按 |
| 字太小 | 瀏覽器再放大到 175% 或 200% 重錄 |
| 中途出現「示範中斷」 | 通常是網路不穩，重新整理後再錄一次 |
| 想只錄其中一段 | 把整支錄完後，用剪輯軟體切出需要的段落 |
